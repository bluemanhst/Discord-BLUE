# Security Policy

## 🛡️ Supported Versions

We actively maintain and provide security updates for the following versions of **Discord BLUE**:

| Version | Supported          | Status             |
| ------- | ------------------ | ------------------ |
| 1.0.x   | :white_check_mark: | Currently Supported |
| < 1.0   | :x:                | Deprecated         |

---

## 🔒 Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability or credential risk, please report it responsibly.

### How to Report:
* **Please DO NOT open a public issue** on GitHub for security vulnerabilities.
* Send a private report directly to the maintainer via:
  - **Email**: [manhstttt@gmail.com](mailto:manhstttt@gmail.com)
  - **Discord**: `bluemanhst` (User ID: `481280614956400690`)

### What to Include in Your Report:
1. Description of the vulnerability.
2. Step-by-step instructions or proof-of-concept to reproduce the issue.
3. Potential impact of the vulnerability.

### Response Time:
We will acknowledge receipt of your vulnerability report within **48 hours** and provide regular updates regarding our investigation and remediation steps.

---

## ⚠️ Important Security Notice for Users

* **Never Share `config.json`**: This file contains your personal Discord tokens. Never commit, upload, or share this file with anyone.
* **Token Safety**: Discord BLUE only communicates directly with official Discord API endpoints (`https://discord.com/api/v9/`). It does not transmit tokens to any third-party servers.
